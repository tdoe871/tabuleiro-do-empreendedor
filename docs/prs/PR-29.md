# PR #29 — Cerrado sin mergear: `dev → qa`, conflicto de historial

- **Rama:** `dev` → `qa`
- **Fecha:** abierto y cerrado 12 nov 2026
- **Resultado:** cerrado sin mergear, reemplazado por el PR #30

## Qué pasó

GitHub marcó conflicto entre `dev` y `qa` en 3 archivos de pruebas e2e. No era un conflicto real de
contenido: `qa` tenía una copia independiente de esos archivos (de trabajo de QA anterior nunca
sincronizado) con el mismo contenido final que `dev`, pero bajo un historial de commits distinto —
git los ve como "add/add" en vez de reconocerlos como el mismo cambio.

## Cómo se resolvió

Se cerró este PR y se creó una rama nueva (`sync/dev-into-qa`) desde `dev`, mezclando `qa` ahí y
resolviendo los 3 conflictos a favor del contenido de `dev` (ya probado). Ver `docs/prs/PR-30.md`.
