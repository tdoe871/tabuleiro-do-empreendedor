# PR #27 — Layout de celular + `turbo.json` sin declarar variables de entorno

- **Rama:** `feature/domain-resend-mobile` → `dev`
- **Fecha:** 11-12 nov 2026, mergeado 12 nov 05:00 UTC
- **Autor:** Brandon (con Claude)

## Por qué

Pedido del equipo: conectar el dominio real + Resend (documentado en
`docs/hosting/ESTADO-HOSTING.md`) y, al revisar la app en el navegador del celular durante esa
misma sesión, se encontró que el layout se rompía en pantallas angostas.

## Qué cambió

- **Mobile** (`apps/web/src/app/globals.css`, dentro de `@media (max-width: 860px)`): las pestañas
  de login (Entrar/Crear cuenta/Código/Mentor) se encimaban; se cambiaron a una cuadrícula de 2
  columnas. La barra superior (topbar) se recortaba; se le permitió crecer en altura. Se ocultó un
  divisor visual (`::before`) que solo tiene sentido en pantallas anchas.
- **`turbo.json`**: se agregó la lista de variables de entorno (`SUPABASE_URL`,
  `DATABASE_URL`, `AUTH_SECRET`, etc.) al task `build`, para que Turborepo invalide el caché de
  build cuando una de ellas cambia en Vercel (sin esto, un cambio de variable podía servir un build
  viejo cacheado).

Detalle completo del dominio/Resend en `docs/hosting/ESTADO-HOSTING.md`.

## Pruebas

- Verificado manualmente en el navegador contra viewports de celular.
- Suite unitaria y e2e en verde.
