# PR #26 — Corregir copy desactualizado de "entrega guardada" + botón de copiar link

- **Rama:** `fix/submission-toast-and-copy-link` → `dev`
- **Fecha:** 11 nov 2026, mergeado 15:47 UTC
- **Autor:** Brandon (con Claude)

## Por qué

El toast que aparece al guardar una entrega seguía diciendo "falta conectar con el backend" en los
4 idiomas, aunque esa conexión real ya existía desde el PR #18 (10 nov) — era texto que nadie
actualizó después de conectar el backend. El idioma español además tenía un error de copy que decía
que un link `http://` también era válido, cuando la regla real exige `https://`.

## Qué cambió

- Corregido el texto del toast en `en/es/fr/pt-BR`.
- Corregido el mensaje de error del link en español.
- Agregado un botón de "copiar" junto al link de invitación del equipo, para que el líder no tenga
  que seleccionar el texto del input a mano.
